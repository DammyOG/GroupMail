Anthropic (Claude)

Leave blank unless Anthropic answers "anthropic-workspace-id is required when authenticating with an identity-linked API key". Find the ID in the Console under Settings → Workspaces — open the workspace and copy the wrkspc_... value from the address bar.

Whichever key you fill in is only used when its provider is selected above. Keys are stored locally in your Chrome profile (chrome.storage.sync) and only ever sent to that provider's own API. Get an OpenAI key at platform.openai.com/api-keys, or an Anthropic key at console.anthropic.com/settings/keys — note this is separate from a claude.ai chat subscription and billed separately. Usage is billed by the provider based on how many emails you label.

Reset tracking

The extension remembers which emails it has already labeled so it doesn't relabel them. If it's telling you emails are "already grouped" when they don't actually have a label in Gmail, that memory has drifted out of sync — reset it below. This does not touch anything in Gmail; it only clears the extension's local memory, so the next "Group Emails" run will re-check every unread email from scratch.
